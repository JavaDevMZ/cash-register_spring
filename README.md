# 🚀 Cash Register Spring

A Spring Boot version of my previous project - an online cash register where workers with different roles can manage products in the warehous, orders and reports

## 🛠️ Features

- ✅ User authentication with Spring Security
- 🗂️ Role-based access control (CASHIER / SENIOR CASHIER / COMMODITY EXPERT)
- 📝 Create, update, delete orders
- 📦 Manage products in the warehouse
- 📄 Report generation
- 🌐 Internationalization


## 🧰 Tech Stack

- **Java 17**
- **Spring Boot**
- **PostgreSQL**
- **Hibernate**
- **HTML**
- **Spring MVC**
